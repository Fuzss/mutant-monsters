# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [v26.3.0-mc26.3.x] - 2026-10-06

### Added

- Add `turns_into_dirt` block tag controlling which blocks seismic waves convert into dirt, replacing the previous
  hardcoded list of blocks

### Changed

- Update to Minecraft 26.3.x
- Chemical X is brewed from a Thick splash potion and a mutant item again instead of being crafted
- Refactor and correct all entity models against the original 1.7.10 mod

### Fixed

- Fix mutant zombie death animation flickering
